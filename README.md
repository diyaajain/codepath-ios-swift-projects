## Notes
- These are course projects built while following CodePath's curriculum, with my own changes and features added along the way.
- Some apps depend on third-party services (Parse/Back4App, Twitter API) that have changed or been retired, so they may not run without updates. API keys have been removed; you'd need your own.
- Requires Xcode. Open the `.xcodeproj` or `.xcworkspace` in each folder. If a folder has a `Podfile`, run `pod install` first.
